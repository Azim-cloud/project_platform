# Отчёт по безопасности приложения

## 1. Защита от SQL-инъекций

**Статус:** ✅ Защищено

**Используется:** SQLAlchemy ORM (все запросы параметризованы)

**Тест:** Попытка ввода `' OR '1'='1` не дала результата — данные защищены.

## 2. Хранение паролей

**Статус:** ✅ Безопасно

**Используется:** SHA-256 + соль

**Тест:** Пароли в базе данных хранятся в хэшированном виде.

## 3. Права доступа

**Статус:** ✅ Настроены

**Проверка:**
- Обычный пользователь не может открыть `/admin`
- Администратор имеет доступ к `/admin`

## 4. Авторизация

**Статус:** ✅ Безопасна

**Используется:** JWT токены (срок действия 24 часа)

## Заключение

Приложение защищено от основных угроз:
- SQL-инъекции ❌ невозможны
- Пароли 🔒 хэшированы
- Доступ 🔐 разграничен
