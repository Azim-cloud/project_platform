# Структура проекта


## Основные файлы

### app/user_system.py
Главный файл приложения. Содержит:
- Модели базы данных
- HTML шаблоны
- Маршруты (API endpoints)
- Логику приложения

### app/main_optimized.py
Оптимизированная версия с улучшенной производительностью.

### projects.db
База данных SQLite с таблицами:
- `users` — пользователи
- `projects` — проекты
- `tasks` — задачи
- `comments` — комментарии
- `notifications` — уведомления
- `activity_logs` — журнал активности
