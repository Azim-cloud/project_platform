# Руководство пользователя
## Онлайн-платформа управления проектами

---

## 1. Введение

Данное руководство поможет вам быстро освоиться с работой в системе управления проектами.

---

## 2. Регистрация и вход

### 2.1. Регистрация

1. Откройте приложение по адресу: `http://localhost:8000`
2. Нажмите **"Зарегистрироваться"**
3. Заполните форму:
   - **Email** — ваш электронный адрес
   - **Имя пользователя** — логин для входа
   - **Полное имя** — ваше имя и фамилия
   - **Пароль** — придумайте пароль (минимум 6 символов)
4. Нажмите **"Зарегистрироваться"**

### 2.2. Вход в систему

1. На странице входа введите:
   - **Имя пользователя**
   - **Пароль**
2. Нажмите **"Войти"**

### 2.3. Восстановление пароля

Если вы забыли пароль:
1. На странице входа нажмите **"Забыли пароль?"**
2. Введите email, указанный при регистрации
3. Перейдите по ссылке, полученной на email
4. Установите новый пароль

---

## 3. Управление проектами

### 3.1. Создание проекта

1. Перейдите на страницу **"Проекты"**
2. Заполните форму слева:
   - **Название** — введите название проекта
   - **Описание** — краткое описание проекта
   - **Статус** — выберите статус
3. Нажмите **"Создать"**

### 3.2. Просмотр проектов

Все ваши проекты отображаются на главной странице в виде карточек.

### 3.3. Поиск проектов

Введите ключевое слово в поле поиска и нажмите **"Найти"**.

### 3.4. Фильтрация проектов

Используйте кнопки фильтрации:
- **Все** — показать все проекты
- **Активные** — только активные проекты
- **Завершенные** — только завершенные
- **Архив** — только архивные проекты

---

## 4. Управление задачами

### 4.1. Создание задачи

1. Перейдите на страницу **"Задачи"**
2. Заполните форму создания задачи:
   - **Название** — название задачи
   - **Описание** — подробное описание
   - **Проект** — выберите проект
   - **Статус** — выберите статус
   - **Приоритет** — выберите приоритет
3. Нажмите **"Создать"**

### 4.2. Изменение статуса задачи

На карточке задачи нажмите одну из кнопок:
- **To Do** — задача в очереди
- **В работу** — задача в процессе выполнения
- **На проверку** — задача на проверке
- **Готово** — задача выполнена

### 4.3. Редактирование задачи

1. Откройте задачу
2. Нажмите **"Редактировать"**
3. Измените нужные поля
4. Нажмите **"Сохранить"**

### 4.4. Удаление задачи

1. Откройте задачу
2. Нажмите **"Удалить"**
3. Подтвердите удаление

### 4.5. Комментарии

1. Откройте задачу
2. Введите комментарий в поле внизу страницы
3. Нажмите **"Отправить"**

---

## 5. Личный кабинет

### 5.1. Просмотр профиля

Нажмите на своё имя в меню или перейдите по ссылке **"Профиль"**.

### 5.2. Редактирование профиля

1. В профиле нажмите **"Редактировать профиль"**
2. Измените данные
3. Нажмите **"Сохранить"**

### 5.3. Смена пароля

1. В профиле нажмите **"Сменить пароль"**
2. Введите текущий пароль
3. Введите новый пароль и подтверждение
4. Нажмите **"Сменить"**

---

## 6. Уведомления

### 6.1. Просмотр уведомлений

Нажмите на значок колокольчика в меню.

### 6.2. Отметка о прочтении

Нажмите **"Прочитано"** рядом с уведомлением.

### 6.3. Отметить все как прочитанные

Нажмите **"Все прочитаны"**.

---

## 7. Административная панель

Доступна только для пользователей с ролью **"admin"**.

### 7.1. Вход как администратор

- **Имя пользователя:** `admin`
- **Пароль:** `admin123`

### 7.2. Управление пользователями

1. Перейдите в **"Админ-панель → Пользователи"**
2. Вы можете:
   - **Деактивировать/Активировать** пользователя
   - **Назначить администратором**

### 7.3. Управление проектами

1. Перейдите в **"Админ-панель → Проекты"**
2. Вы можете удалить любой проект

---

## 8. Мобильная версия

Приложение адаптировано для мобильных устройств:
- Меню сворачивается в бургер-меню (☰)
- Кнопки и поля увеличены для удобства
- Карточки отображаются в одну колонку

---

## 9. Выход из системы

Нажмите **"Выйти"** в меню.
